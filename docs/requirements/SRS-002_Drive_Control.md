## 1. 개요

### 1.1 목적
SRS-001이 구축한 ECU 플랫폼(CAN·UDS·부트로더·A/B Secure OTA)에 **폐루프 구동 제어 계층**을 추가한다. 엔코더(휠 속도)·IMU(헤딩)를 피드백으로 한 **cascaded PID 제어**와 **센서퓨전**을 구현하고, 이를 주행 제어 모드(정속·차선유지·차간거리 유지·긴급정지)로 실증한다. 본 명세는 SRS-001의 한계 L-7을 닫는 후속 요구를 정의한다.

### 1.2 정직 스코핑 (한계)
- 소형 차량(RC) · 실 보드 2대 기반. **제어/펌웨어 계층 중심**.
- 차선유지(LKAS)·차간거리(ACC)·긴급정지(AEB)는 **원리 수준 모사**이며, 카메라 인지·자율주행·production 인증이 아니다. 본 문서는 "자율주행" 용어를 사용하지 않는다.
- ASIL 등급은 [HARA-001]의 *표현(represented) 차량 기능 기준*이며 실제 RC 물리 심각도와 구분한다.

---

## 2. 범위

### 2.1 In Scope
1. 엔코더 휠 속도 취득(타이머 인코더 모드) 및 RPM 추정
2. IMU(BNO086) 취득 및 헤딩/요레이트 추정 (I2C/Qwiic)
3. 센서퓨전 — 엔코더 오도메트리 + IMU(상보/칼만) 기반 상태 추정
4. 내부 루프: 바퀴별 **속도 PID**
5. 외부 루프: **헤딩/경로 PID** (cascaded)
6. 주행 제어 모드: 정속 주행 · 차선유지(LKAS 모사) · 차간거리 유지(ACC 모사) · 긴급정지(AEB)
7. 제어 관련 CAN 신호 추가 및 ECU 간 분산 제어
8. HARA(H-5~H-8) 유도 안전 요구(과속 차단·횡방향 안전·센서결함 검출→Safe State)
9. 단위(제어/퓨전 수학)·on-target(주행 거동) 검증, 제어주기 타이밍 측정

### 2.2 Out of Scope
| 제외 | 사유 |
|---|---|
| 카메라/CV 기반 차선 인식 | 인지(자율주행 SW) 트랙 — 본 프로젝트는 제어/펌웨어 계층 |
| 경로 계획·의사결정(autonomy) | 상위 SW 영역, 본 범위 밖 |
| 라인센서 정밀 추종(현 4ch 디지털) | 아날로그 리플렉턴스 어레이 입고 시 LKAS 모드에 한정 적용(부품 ADR) |

---

## 3. 용어 · 제어 구조

- **Cascaded 제어**: 내부 속도 루프(엔코더) + 외부 헤딩/경로 루프(IMU·라인) 2단.
- **상태 추정(State Estimation)**: 엔코더 오도메트리 + IMU 융합으로 속도·헤딩(·위치) 추정.
- **주행 제어 모드**: 정속(Cruise) / 차선유지(LKAS) / 차간거리(ACC) / 긴급정지(AEB).

---

## 4. 기능 요구사항

### 4.1 센서 취득 · 퓨전 (FR-FUS)
| ID | 요구사항 | 등급 | 수용 기준 |
|---|---|---|---|
| FR-FUS-001 | DriveECU는 좌·우 휠 엔코더를 타이머 인코더 모드로 읽어 RPM을 추정해야 한다. | Must | 카운터→RPM 변환이 ±5% 이내, 측정 주기 ≤ 10ms (수치 TBD) |
| FR-FUS-002 | SensorECU는 BNO086 IMU에서 요레이트·헤딩을 취득해야 한다. | Must | I2C/Qwiic 취득, 유효 헤딩(deg) 산출 (드리프트 보정 방식 §SDD) |
| FR-FUS-003 | 시스템은 엔코더 오도메트리와 IMU를 융합해 헤딩 추정치를 산출해야 한다. | Must | 상보/칼만 필터, 정적·회전 시 헤딩 오차 한계 TBD |
| FR-FUS-004 | 센서 입력은 stale/결함 검출(plausibility·timeout)을 거쳐야 한다. | Must | 신호 timeout/범위이탈 시 무효 처리 → FSR-CTL-04 연계 |

### 4.2 폐루프 제어 (FR-CTL)
| ID | 요구사항 | 등급 | 수용 기준 |
|---|---|---|---|
| FR-CTL-001 | DriveECU는 바퀴별 목표 속도를 **속도 PID**로 추종해야 한다(내부 루프). | Must | 스텝 응답 정착시간·정상상태오차 한계 TBD, 안티와인드업 포함 |
| FR-CTL-002 | DriveECU는 목표 헤딩/경로 오차를 **외부 루프 PID**로 보정해야 한다(cascaded). | Must | 외부 루프 출력이 좌우 속도 setpoint 차로 반영 |
| FR-CTL-003 | 제어기는 주행 제어 모드(정속/LKAS/ACC/AEB)를 관리하는 상태기계를 가져야 한다. | Must | 모드 전이 조건·우선순위 정의(AEB 최우선) |
| FR-CTL-004 | **정속(Cruise)**: 목표 속도를 유지해야 한다. | Must | 목표 RPM 대비 정상상태오차 한계 TBD |
| FR-CTL-005 | **차선유지(LKAS 모사)**: 라인 위치 오차를 외부 루프로 보정해 경로를 추종해야 한다. | Should | 아날로그 라인 어레이 입고 시. 라인 중앙오차 한계 TBD |
| FR-CTL-006 | **차간거리(ACC 모사)**: 전방 거리(ToF/초음파) 기반으로 목표 속도를 가감해 거리·정속을 유지해야 한다. | Must | 설정 거리 유지, 접근 시 감속 |
| FR-CTL-007 | **긴급정지(AEB)**: 임계 거리 이내 급접근 시 즉시 정지해야 한다(최우선). | Must | SRS-001 FR-SEN-002(10cm) 인프라 재사용, 모든 모드보다 우선 |
| FR-CTL-008 | 제어 상태(모드·목표/실제 속도·헤딩)를 CAN으로 보고해야 한다. | Should | §6 신규 CAN 신호로 송신 |

### 4.3 실시간/성능 (NFR-CTL)
| ID | 요구사항 | 등급 | 수용 기준 |
|---|---|---|---|
| NFR-CTL-001 | 제어 루프는 고정 주기로 실행되어야 한다. | Must | 제어주기 Tc(예 ≤10ms)·지터 한계 TBD, GPIO+스코프로 측정 |
| NFR-CTL-002 | 제어 연산은 주기 예산 내 완료되어야 한다(오버런 없음). | Must | ISR/루프 실행시간 ≤ Tc, CPU 부하 기록 |

### 4.4 기능안전 요구 (FSR-CTL) — [HARA-001] §3/§4 유도
| ID | 요구사항 | 등급 | 출처(SG) |
|---|---|---|---|
| FSR-CTL-01 | 제어 출력(속도)은 상한으로 saturate되어 의도치 않은 과속/폭주를 방지해야 한다. | Must | SG-5 (H-5) |
| FSR-CTL-02 | 헤딩/경로 오차가 한계 초과 또는 외부 루프 발산 시 감속·정지(Safe State)해야 한다. | Must | SG-6 (H-6) |
| FSR-CTL-03 | 차간거리 제어는 최소 안전거리를 보장하고, 실패 시 AEB(정지)로 폴백해야 한다. | Must | SG-7 (H-7) |
| FSR-CTL-04 | 엔코더/IMU/거리 신호의 stale·손상을 검출(plausibility, **E2E**)하고 검출 시 Safe State로 진입해야 한다. | Must | SG-8 (H-8) · TSR-1.2(E2E) 연계 |

> FSR-CTL-04의 E2E(Alive+CRC)는 HARA-001이 이미 드러낸 갭(TSR-1.2)과 동일 메커니즘 → 안전 신호 보호를 제어 신호로 확장.

## 5. 인터페이스 (신규 CAN 신호 — 할당은 설계 단계 SDD/ADR)
| 제안 ID | 방향 | 내용 |
|---|---|---|
| 0x110 | DriveECU → bus | 제어 상태: 모드·목표속도·실제속도·헤딩 |
| 0x202 | SensorECU → DriveECU | IMU: 헤딩·요레이트 |
| 0x111 | (GW/입력) → DriveECU | 모드/목표 setpoint 명령 |

(기존 0x100 Drive 상태·0x200 거리·0x201 Sensor hb는 SRS-001 유지)

## 6. 추적성 (요약)
- **상향:** FSR-CTL-01~04 ← [HARA-001] SG-5~SG-8(H-5~H-8).
- **하향:** FR-FUS/FR-CTL/NFR-CTL → SDD-001 제어 컴포넌트(확장) → 코드 → 단위/SIT TC.
- **대체 관계:** FR-CTL-004(정속)·FR-CTL-007(AEB)는 SRS-001 FR-DRV-001/003(개루프 직진·정지)을 폐루프로 확장·대체. L-7 해소.
- 상세 행렬은 [RTM-001]에 통합(분기 금지).
